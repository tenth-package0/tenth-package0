# No-AI Lab

This is my space for practicing software development without artificial-intelligence assistance.

## The rule

All project work placed in this folder is completed without AI in any way, shape, or form.

That means no AI for:

- idea generation or project selection;
- architecture or technical planning;
- code generation or autocomplete;
- debugging or error explanation;
- code review or refactoring;
- documentation, tests, or commit messages;
- research, summaries, or implementation guidance.

The code is planned, written, tested, reviewed, and documented manually. Traditional documentation, books, specifications, and non-AI search are allowed.

## Cadence

I touch this space **at least once every week**. Each session is recorded in [LOG.md](./LOG.md) with the date, project, and a short description of the work completed.

## Integrity note

The folder structure and policy text were set up with assistance. They are administrative scaffolding and are not part of the no-AI coding challenge. Only work explicitly recorded in the log counts.
